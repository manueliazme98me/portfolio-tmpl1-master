# Portfolio Template Collection

A modern portfolio template package featuring multiple React and Next.js implementations for personal branding, creative portfolios, and professional resumes.

## Overview

This repository contains a curated set of portfolio starter projects designed for developers, designers, freelancers, and digital professionals. Each version includes a different layout style and presentation approach while maintaining a clean, responsive, and modern aesthetic.

## Included Projects

- React version with Bostami theme
- Next.js portfolio templates with box layout and regular layout
- Documentation assets and design resources
- Reusable UI sections for portfolio, resume, blog, and contact pages

## Getting Started

### React version

```bash
cd react-version/bostami
npm install
npm start
```

### Next.js version

```bash
cd nextjs-version/bostami/box-layout
npm install
npm run dev
```

## Customization

Update the content and styling in each project folder to match your personal brand, work experience, portfolio items, and contact details.

Common customization areas:

- personal bio and profile details
- work experience and education
- portfolio project list
- social links and contact information
- colors, typography, and layout settings
